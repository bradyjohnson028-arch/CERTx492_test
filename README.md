# CERTx492_test

Business question: How do daily rental volumes vary with calendar and weather conditions, and what limitations should an operations manager consider when interpreting those patterns?

Data source: UCI Bike Sharing dataset. Week 1 uses the January 1–7, 2011 sample included in the notebook; later modules use the full daily file.

Notebook purpose: This notebook practices basic Python calculations, explores seven days of bike rental data, calculates casual rental percentages, and documents an AI-assisted code correction checked with a calculator.

Data attribution: Fanaee-T, H. (2013). Bike Sharing [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5W894. Licensed under CC BY 4.0.

Week 1 adaptation: the first seven daily records (January 1–7, 2011), with four original columns selected. Original dates and rental counts are unchanged. The casual_pct column is calculated during the activity.
